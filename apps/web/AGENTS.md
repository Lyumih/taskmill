# Правила веб-приложения

Эти правила относятся к коду внутри `apps/web` и могут дополняться по мере развития проекта.

## Структура

- Размещай страницы в `src/pages`, лейауты страниц в `src/layouts`, переиспользуемые компоненты в `src/components`, утилиты в `src/utils`.
- Каждый компонент и лейаут размещай в отдельной папке с именем в PascalCase и файлом `index.tsx`: например, `src/components/TaskCard/index.tsx` или `src/layouts/MainLayout/index.tsx`.
- Сохраняй принцип «один компонент на файл». Если в `index.tsx` появляется второй самостоятельный компонент, вынеси его в отдельную папку по тем же правилам.
- Поддерживай файлы компонентов компактными. Выноси отдельные компоненты или утилиты, когда это делает структуру и ответственность кода яснее.

## Ant Design и компоновка

- Предпочитай компоненты Ant Design нативным HTML-элементам. Для flex-компоновки сначала рассмотри `Flex`, а не `div` с CSS-flex.
- Не заменяй `div` на `Flex`, если нужен семантический HTML-элемент или контейнер не выполняет flex-компоновку.
- Перед использованием `Flex` сверяйся с его API и применяй подходящие свойства компонента, а не добавляй CSS для уже поддерживаемых возможностей.
- По возможности собирай интерфейс из компонентов Ant Design и избегай дополнительных CSS-стилей.
- Не создавай классические `.css`-файлы. Для небольшого числа локальных стилевых свойств используй `style={{ ... }}`; если нужны несколько классов или более сложные стили, используй `createStyles` из `antd-style`.
