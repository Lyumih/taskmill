# Редактирование задачи Taskmill

Внеси в существующую задачу конкретную правку, указанную пользователем. Не обновляй общий прогресс задачи; для этого используй скилл `taskmill-update`.

## Входные данные

Определи задачу по точному пути к файлу или ID, а также установи, какие поля или содержимое нужно изменить. Если задача или новое значение неоднозначны, сначала уточни.

Пример: `taskmill-edit tasks/0001/task0001.md: измени заголовок и исправь ссылку на Jira`

## Порядок работы

1. Прочитай выбранную задачу и её формат. Измени только запрошенные сведения и минимально необходимый связанный текст, чтобы запись оставалась согласованной.
2. При редактировании через консоль или файл обнови выбранный файл задачи, сохранив не относящиеся к правке поля, форматирование и заметки пользователя.
3. Если пользователь просит внести правку через веб-интерфейс Taskmill, используй его только при наличии доступа и настоящей операции сохранения. Иначе сообщи, что веб-редактирование в текущем сеансе недоступно. Не утверждай, что файл сохранён через веб-приложение, если менял его напрямую.
4. Не вноси дополнительные исправления, не обновляй сведения из Git/Jira/MR и не меняй код проекта без прямой просьбы.
5. Проверь сохранённые значения и сообщи, какой файл или интерфейс был изменён.
