# Редактирование файла Taskmill

Внеси в файл данных или конфигурации Taskmill только конкретную правку, указанную пользователем. Объектом правки может быть задача Taskmill, блок проекта или отдельное поле. Не редактируй план выполнения агента и не обновляй общий прогресс задачи; для прогресса используй скилл `taskmill-update`.

## Входные данные

Определи файл по точному пути внутри `.taskmill` либо по корню проекта вместе с ID/названием объекта. Если указан корень, найди ближайший `.taskmill/config.json`; задачи ищи только в `.taskmill/tasks/<taskId>.ts`, конфигурацию — только в `.taskmill/config.json`. Для блока используй его стабильный ID, если он указан; название служит для проверки. Если файл или объект нельзя однозначно определить, сначала уточни. Если новое значение неоднозначно, сначала уточни.

Примеры:

- `taskmill-edit .taskmill/tasks/0001.ts: измени заголовок и исправь ссылку на Jira`
- `taskmill-edit C:/project/.taskmill/config.json, блок project-context: добавь указанный URL в ссылки проекта`

## Порядок работы

1. Найди и прочитай выбранный файл, проверь его формат и соответствие объекта указанному ID/названию. Если передан корень проекта, найди в нём `.taskmill/config.json` и ищи данные только внутри `.taskmill/`. Не используй `apps/web/mock` или другие каталоги исходников Taskmill как хранилище проекта.
2. Измени только указанные поля или содержимое. Перед записью проверь, что путь остаётся внутри `<project-root>/.taskmill/`. Для блока сохрани его ID, структуру остальных полей, соседние блоки и комментарии, которые не входят в явный diff; не переписывай файл целиком без необходимости.
3. Если пользователь просит внести правку через веб-интерфейс Taskmill, используй его только при наличии доступа и настоящей операции сохранения. Иначе сообщи, что веб-редактирование в текущем сеансе недоступно. Не утверждай, что файл сохранён через веб-приложение, если менял его напрямую.
4. Не вноси дополнительные исправления, не обновляй сведения из Git/Jira/MR и не меняй код приложения без прямой просьбы.
5. Проверь сохранённые значения и сообщи, какой файл и какие поля были изменены.
