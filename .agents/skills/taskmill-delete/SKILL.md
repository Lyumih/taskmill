# Удаление задачи Taskmill

Перемести запись задачи из активного списка в корзину, откуда её можно восстановить. Никогда не удаляй данные задачи безвозвратно.

## Входные данные

Предпочтительно указывать точный путь к файлу задачи или её ID. Понятие «текущая задача» можно определить по контексту диалога или проекта, только если ему соответствует ровно одна задача. Если подходят несколько задач, уточни, какую переместить.

Пример: `taskmill-delete tasks/0001/task0001.md`

## Порядок работы

1. До любых изменений точно определи и проверь файл задачи. Если ссылка на задачу неоднозначна, не определяй её только по текущей ветке Git.
2. Если для хранилища задач настроена корзина, используй её. В противном случае найди ближайший распознаваемый корень хранилища (например, `tasks/` или `.taskmill/tasks/`) и перемести файл в его каталог `.trash/`, в уникальный каталог с временной меткой, сохранив относительный путь. Если корень хранилища определить нельзя, спроси, куда переместить файл.
3. Перемещай только выбранную запись задачи. Не удаляй её безвозвратно, не очищай корзину и не удаляй соседние каталоги или вложения.
4. Если целевой файл уже существует или перемещение нельзя проверить, остановись, ничего не перезаписывай и сообщи о проблеме.
5. После перемещения сообщи исходный путь и путь в корзине, откуда запись можно восстановить.
