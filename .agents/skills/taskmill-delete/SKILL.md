# Удаление задачи Taskmill

Перемести запись задачи из активного списка в корзину, откуда её можно восстановить. Никогда не удаляй данные задачи безвозвратно.

## Входные данные

Предпочтительно указывать точный путь к файлу задачи внутри `.taskmill` или её ID. Если указан ID, ищи только `.taskmill/tasks/<taskId>.ts` относительно корня проекта. Понятие «текущая задача» можно определить по контексту диалога или проекта, только если ему соответствует ровно один файл задачи в `.taskmill/tasks/`. Если подходят несколько задач, уточни, какую переместить.

Пример: `taskmill-delete .taskmill/tasks/0001.ts`

## Порядок работы

1. До любых изменений определи корень проекта по явному пути или ближайшему родительскому каталогу с `.taskmill/config.json`. Точно проверь файл задачи и убедись, что он находится внутри `<project-root>/.taskmill/tasks/`. Если корень или задача неоднозначны, не определяй их только по текущей ветке Git и уточни у пользователя.
2. Перемести файл в `<project-root>/.taskmill/.trash/<timestamp>/tasks/<taskId>.ts`, сохранив исходный путь относительно `.taskmill/`. Используй уникальный timestamp; если цель существует или формат корня не подтверждён, остановись и спроси пользователя. Не ищи корзину вне `.taskmill`.
3. Перемещай только выбранную запись задачи. Не удаляй её безвозвратно, не очищай корзину и не удаляй соседние каталоги или вложения. Не изменяй Taskmill source tree или dashboard mock registry.
4. Если целевой файл уже существует или перемещение нельзя проверить, остановись, ничего не перезаписывай и сообщи о проблеме.
5. После перемещения сообщи исходный путь и путь в корзине, откуда запись можно восстановить.
